# Context

> The Wikipedia of the lake. Agents read Context to **understand**; they follow [[Statute]] to **act**.

Each product or domain gets its own folder with a hub file, created from [[_tpl_product]]:

```
10_Context/{Product}/
├── {Product}.md      # hub
├── architecture/
├── specs/            # _tpl_spec
├── components/       # _tpl_component
└── decisions/        # _tpl_adr
```

A "product" is any bounded domain: a service, a team, a language you study, a channel you run.
