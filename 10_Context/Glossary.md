# Glossary

**Agent** — an AI operator that executes Skills according to Statute. See [[Roles]].

**Architect** — the human owner of the Statute. Approves all material changes.

**Case** — a documented incident, near-miss, or decision that informs Statute evolution.

**Codex** — the constitution of the framework. Shipped with the template, identical in every lake.

**Lake** — one Obsidian vault + git repo with a `lake.yaml`. Either `main` or `member`.

**MCP** — Model Context Protocol. The only way agents touch external systems.

**Override** — a member-lake document that replaces a main-lake document (`overrides:` field).

**Rule** — an atomic constraint in the Statute. Format: `RULE-{DOMAIN}-{NNN}`.

**Skill** — a modular capability with inputs, outputs, and governing rules.

**Statute** — the law of the system: rules, workflows, policies, checklists.

**Workflow** — an ordered procedure for a recurring task. Format: `WFLOW-{DOMAIN}-{NNN}`.
